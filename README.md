# 💼 Finance Telegram Mini App йо

Личный финансовый трекер — Telegram Mini App на Flask + SQLite.

## 📁 Структура

```
finance_app/
├── app.py              ← Flask-бэкенд (API + отдача фронта)
├── requirements.txt
├── finance.db          ← SQLite (создаётся автоматически)
└── static/
    └── index.html      ← Telegram Mini App (фронтенд)
```

---

## 🚀 Быстрый старт

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Запустить сервер

```bash
python app.py
```

Открыть в браузере для проверки: `http://localhost:5000`  
База данных `finance.db` создаётся автоматически с демо-данными.

---

## 🌐 Деплой для Telegram (нужен HTTPS)

### Вариант А — ngrok (быстрое тестирование)

```bash
ngrok http 5000
# → получите URL вида https://xxxx.ngrok.io
```

### Вариант Б — Railway / Render / VPS

```bash
pip install gunicorn
gunicorn app:app -b 0.0.0.0:8000
```

Настроить nginx/caddy для HTTPS → задать URL в @BotFather.

### Настройка бота

```
@BotFather → /newbot → /newapp → указать HTTPS-URL
```
